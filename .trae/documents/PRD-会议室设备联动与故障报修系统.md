## 1. 产品概述

会议室设备联动与故障报修系统，用于企业内部会议室设备的全生命周期管理，解决会议室设备调度混乱、故障报修不及时、设备使用效率低下等问题。目标用户为企业行政管理员和普通员工，通过统一的设备管理、会议预约、故障报修一体化平台，提升会议室设备的使用效率和维护效率。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|---------|---------|
| 系统管理员 | 默认账号 | 维护会议室、设备全生命周期管理、查看所有会议、处理故障、导出报告 |
| 普通用户 | 无需注册，模拟登录 | 创建会议、预约设备、上报异常、查看自己的会议 |

### 2.2 功能模块

5. **检查任务列表**：会议前设备检查任务管理
6. **故障报修**：故障上报、处理、关闭流程
7. **报告导出**：设备使用报告导出功能

## 3. 核心流程

### 3.1 会议创建与设备联动流程

管理员或用户创建会议，选择会议室和时间段，系统自动展示该会议室可用设备供勾选。系统校验设备是否故障、是否被其他会议占用，校验通过后保存会议并关联设备。

### 3.2 会议开始前检查流程

会议开始前30分钟，系统自动生成设备检查任务。检查人员逐项检查设备状态，如有异常直接上报故障。检查未完成时，系统拦截会议开始操作。

### 3.3 会议结束流程

会议结束后，记录设备归还状态、使用反馈。如有异常，可上报故障。系统自动释放设备占用。

### 3.4 故障报修流程

用户或检查人员上报故障，系统创建设备故障状态并拦截该设备在其他会议中的分配。管理员分配处理人，处理完成后关闭故障单，设备恢复可用状态。

```mermaid
    J -->|"完成" L["开始会议"]
    L --> M["会议结束"]
    M --> N["记录使用反馈"]
    N --> O["释放设备占用"]
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝色系（#1e3a5f 深蓝、#2563eb 蓝色），辅以青色（#0891b2）作为强调色
- 辅助色：绿色表示正常、红色表示故障、橙色表示警告、灰色表示空闲
- 按钮风格：圆角矩形，主按钮填充色背景+白色文字，悬停有深色渐变
- 字体：使用思源黑体 / PingFang SC，标题字号16-24px，正文字号13-14px
- 布局风格：顶部导航栏+左侧侧边栏的经典后台管理布局，卡片式内容展示
- 图标风格：线性简洁图标，使用Lucide图标库

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|-----------|---------|--------|
| 设备状态墙 | 状态概览 | 状态卡片网格布局，每个会议室一个卡片，显示会议室名称、设备数量、状态标签 |
| 会议日历 | 日历视图 | 月视图日历，会议块按时间轴展示，颜色区分会议状态 |
| 设备管理 | 数据表格 | 表格展示设备列表，支持搜索、筛选、分页 |
| 会议管理 | 表单 | 分步表单，会议室选择、时间选择、设备勾选 |
| 检查任务 | 任务卡片 | 待办卡片列表，点击展开检查项 |
| 故障报修 | 故障单卡片 | 状态时间线展示故障处理进度 |
| 报告导出 | 导出面板 | 日期范围选择器、导出选项、导出历史列表 |

### 4.3 响应式

桌面端优先设计，主要适配1920x1080及以上分辨率，侧边栏固定宽度240px，内容区自适应。

## 5. 关键业务拦截规则

1. 设备故障拦截：故障状态设备不可在新会议中选择
2. 设备占用拦截：同一时间段同一设备不可被多个会议占用
3. 检查未完成拦截：会议开始前必须完成设备检查
4. 故障单未关闭拦截：故障单未关闭时设备不可被分配到其他会议
