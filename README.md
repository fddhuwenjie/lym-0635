# 会议室设备联动与故障报修系统

任务类型：0-1代码生成

业务领域：全栈Web应用

修改范围：跨模块多文件

任务难度：中等偏难

题面：

开发一个会议室设备联动与故障报修系统，管理员维护会议室、投影、音响、门禁和网络设备，用户创建会议时可勾选需要联动的设备清单。正常会议开始前系统生成设备检查任务，结束后记录设备归还、使用反馈和异常上报。设备已故障、同一设备被多个会议占用、检查未完成仍开始会议、故障单未关闭再次分配都要拦截。系统需要设备状态墙、会议日历、检查任务列表和使用报告导出，导出包含设备占用、检查结果、故障处理人和生成时间。重启后会议记录、设备占用、故障处理和导出历史保持一致。验收要包含会议取消释放设备、故障修复后重新可选，并检查临时换房后的设备清单同步。
